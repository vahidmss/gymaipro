# GymAI Exercises — ۳۰۰ حرکت (Code Snippets)

## نتیجه بررسی کاتالوگ فعلی (~۲۱۴ حرکت)

خیلی از نام‌های رایج باشگاهی **وجود دارند** ولی با عنوان رسمی متفاوت:

| جستجوی کاربر | عنوان فعلی در دیتابیس |
|---|---|
| پرس بالاسینه | پرس سینه شیب دار |
| لت پولداون / لت سیکمش جلو | زیربغل سیمکش |
| جلو پا / لگ اکستنشن | اکستنشن پا |
| فیس پول | پاروی صورت |
| هک اسکات | هاک اسکات |
| پک دک | فلای پک دستگاه |

پس دو کار لازم بود: **غنی‌سازی alias** + **۱۰۰ حرکت جدید واقعاً کم**.

---

## روش deploy

### 1) اسنیپت CORE (آپدیت لازم)
- `CODE_SNIPPET_POP20_CORE.php` — Run everywhere
- محتوای جدید را جایگزین کن (batch 12–16 + دکمه alias)

### 2) اسنیپت Alias (جدید — مهم برای سرچ)
- `CODE_SNIPPET_IRAN_ALIASES_PATCH.php` — Run everywhere

### 3) فایل‌های batch در `wp-content/gymai-seed/`
```
pop20-batch1.php … pop20-batch16.php
```
(حداقل batch 12 تا 16 را کپی کن)

### 4) اجرا در وردپرس
**ابزارها → GymAI Exercises**

1. اول دکمه **«بروزرسانی نام‌های جایگزین»** را بزن  
   (تا «پرس بالاسینه» و «لت پولداون» پیدا شوند)
2. سپس batch 12 تا 16 را یکی‌یکی اجرا کن = **۱۰۰ حرکت جدید** (۲۰۱ تا ۳۰۰)
3. برای حرکات قدیمی batch 1 و 3: تیک «بروزرسانی موجود» + اجرای دوباره (اختیاری ولی توصیه‌شده)

## Batch 12 (201–220) — پا / ران / هیپ
داخل/خارج ران، هیپ تراست دستگاه، سیسی/بلت/زرچر/سیفتی اسکات، لگ پرس ۴۵، ریورس هایپر، GHR، …

## Batch 13 (221–240) — سینه / پشت
قفسه بالاسینه، کراس اور بالا/پایین، پرس همر، سیل رو، دیپ دستگاه، پول‌آپ خنثی، …

## Batch 14 (241–260) — شانه / بازو
شراگ هالتر، آپرایت رو، اکسترنال روتیشن، اسکال کراشر، فرنچ پرس، دراگ/زوتمن، مچ، …

## Batch 15 (261–280) — Core / کاردیو / فانکشنال
برپی، مانتین کلایمبر، پاور کلین، وال بال، روئینگ/اسالت/اسکی ارگ، اسلد، …

## Batch 16 (281–300) — تکمیل باشگاهی
سامو/پلایه اسکات، کلام‌شل، پیستول، کوپنهاگن، ریورس پک‌دک، یوک واک، …

## بعد از seed
1. اسنیپت **v3.6 Output Patch** را با نسخهٔ جدید جایگزین/فعال کن (الزامی برای sync امن)
2. ابزارها → GymAI Exercises → **بازنویسی meta از اسنیپت‌ها**
3. از اپ: همگام‌سازی تمرین‌ها (WP → Supabase)
4. تست سرچ: `پرس بالاسینه`، `لت پولداون`، `لت سیکمش`، `جلو پا`، `فیس پول`
5. Rank Math: از لیست پست‌ها «بروزرسانی»

> **هشدار sync:** بدون پچ v3.6، به‌روزرسانی اپ می‌تواند `main_muscle`/heatmap غلط را دوباره روی سوپابیس بنویسد. جزئیات: `../gymai-v3-snippets/README.md`
